# JAPAN ATHLETE CONNECT
GitHub Pagesでそのまま公開できるフロントエンド・プロトタイプ。

## GitHub Pages
1. index.html / style.css / app.js をリポジトリ直下へアップロード
2. Settings → Pages
3. Deploy from a branch → main → /(root) → Save

## 実装済み
- PC/スマホ対応
- サービスTOP
- 選手DB（ダミーデータ）
- 競技/年代/地域/Score検索
- 選手詳細・5項目Physical Score
- Scout / Businessの価値設計
- 測定料 / Scout閲覧料 / 企業閲覧料の収益モデル
- Login UI

## 本番版で必要
認証・権限、DB、測定システム連携、同意管理、動画、決済、お気に入り、スカウト打診、スポンサー/採用提案、管理画面、監査ログ、統計データ画面。

※選手名・測定値はすべてデモ用ダミーデータ。
