# JAPAN ATHLETE CONNECT v2
GitHub Pagesにそのままアップできる画像込みフロントエンド・プロトタイプです。

## ファイル構成
- index.html
- style.css
- app.js
- assets/platform-visual.png

## GitHub Pages公開
1. ZIPを解凍
2. 4ファイル/フォルダをGitHubリポジトリのルートへアップロード
3. Settings → Pages
4. Deploy from a branch
5. main / (root) → Save
